# Brand-Visibility-Intelligence-Dashboard
The goal is to analyze how different brands perform in search rankings, pricing strategies, and platform competition.

# Overview
This project analyzes product visibility, ratings, pricing, and reviews across multiple e-commerce platforms.

# Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- SQLite

# Features
- Interactive Dashboard
- KPI Metrics
- Product Search
- Platform Filters
- CSV Download
- Data Visualization
