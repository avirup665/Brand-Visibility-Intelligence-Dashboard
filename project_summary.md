# Project Summary

## Title
Brand Visibility Intelligence Dashboard

## Domain
E-commerce Analytics, Digital Marketing Intelligence, and Business Intelligence

## Summary
This project analyzes how brands perform across e-commerce platforms by studying product listings, prices, ratings, reviews, ranking positions, platform distribution, and visibility score.

## Technical Stack
Python, Pandas, NumPy, SQLite, Plotly, Streamlit, Requests, SerpAPI.

## Deliverables
- Source code
- Cleaned dataset
- SQLite database
- Streamlit dashboard
- Data quality report
- GitHub-ready documentation
